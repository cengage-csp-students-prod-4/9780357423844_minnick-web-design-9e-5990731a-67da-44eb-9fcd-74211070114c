Hexadecimal uses a six-digit base-16 value (#RRGGBB) from 00 to FF per channel. RGB uses decimal values (0-255) for red, green, and blue. HSL uses hue (0-360 degrees), saturation (0-100%), and lightness (0-100%), making it more intuitive for adjustments.

Preferred color code format: HSL, because it is easier to adjust lightness and saturation without recalculating channel values.

HWB (Hue-Whiteness-Blackness) represents colors by hue plus the amount of white and black mixed in. It is similar to HSL but directly controls added white and black to a pure hue.

CMYK (Cyan-Magenta-Yellow-Key/Black) is a subtractive color model used in printing. It defines colors by percentages of ink needed, subtracting light rather than adding it like RGB.
